# YouTube 共有リンクの追跡除去

YouTube 標準のコピー、SNS 共有、埋め込み機能をそのまま使い、リンクを整理します。ボタンは追加しません。

si と feature=shared を除去し、開始時間、再生リスト、再生オプションを保持します。SNS 共有先 URL 内でエンコードされた YouTube リンクも処理し、iframe の si を生成する共有識別子を除去します。

Tampermonkey でインストールした後、YouTube を再読み込みしてください。旧版は更新または置き換え、二重に有効化しないでください。

対象の YouTube ページ内でローカルに処理します。追加の通信、外部コードの読み込み、共有履歴の保存、既存クリップボードの読み取りは行いません。YouTube や共有先のサイト自体の解析機能は停止しません。

主にデスクトップ版 Chrome で検証しています。他のブラウザーは追加検証が必要です。スマートフォンの YouTube アプリは対象外です。

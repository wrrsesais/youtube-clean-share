# YouTube : liens de partage sans suivi

Utilise les commandes natives de YouTube pour copier, partager et intégrer les vidéos. Aucun bouton supplémentaire.

Supprime si et feature=shared tout en conservant le début de lecture, les playlists et les options du lecteur. Nettoie aussi les liens YouTube encodés dans les URL de partage et retire l’identifiant utilisé pour générer si dans le code iframe.

Installez le script avec Tampermonkey, puis rechargez YouTube. Mettez à jour ou remplacez l’ancienne version ; ne laissez pas les deux activées.

Le traitement reste local aux pages YouTube indiquées. Aucune requête réseau supplémentaire, aucun code externe, aucun historique de partage et aucune lecture du contenu existant du presse-papiers. Les outils d’analyse de YouTube et des sites de destination restent indépendants.

Principalement vérifié dans Chrome sur ordinateur. Les autres navigateurs demandent des tests supplémentaires. L’application mobile YouTube n’est pas prise en charge.

# YouTube 分享链接净化

继续使用 YouTube 原生的复制、社交分享和嵌入功能，不添加任何额外按钮。

移除 si 和 feature=shared，保留开始时间、播放列表与播放选项。清理社交分享目标中经过编码的 YouTube 链接，并移除用于生成 iframe 中 si 的分享归因标识。

用 Tampermonkey 安装后刷新 YouTube。旧版用户请更新或替换原脚本，不要同时启用两份。

仅在列出的 YouTube 网页本地处理。不增加网络请求，不加载外部代码，不保存分享历史，不读取已有剪贴板。删除链接参数并不能关闭 YouTube 自身或目标网站的统计追踪。

主要在桌面 Chrome 验证；Edge 等其他浏览器仍需进一步测试，不能保证所有能装油猴的浏览器均兼容。不作用于手机 YouTube App。
